# Progetto_Bayesian_Statistics

- After cloning create folders data, logs, results. Put the dataset into data folder.
- you can change the script in src/modules/sampler for you sampling parameters. You can run it by, `python3 -m src.modules.sampler`

- you can create your models in folder src/stan_models/ab_stan_gen or ab_stan_neg or create new script with your customizations. You can then run it by `python3 -m src.stan_models.ab_stan_neg [N]` where N is number of threat you want to use.
